# 📦 Organizador de Pedidos

Ferramenta web simples para cadastrar e acompanhar pedidos de clientes, com controle de status (pendente, separado, entregue), busca e filtros.

## 💡 Motivação

Trabalho em um supermercado onde recebo e organizo pedidos de clientes via WhatsApp, controlando manualmente o que já foi separado e o que ainda falta entregar. Esse projeto nasceu dessa experiência real: uma versão digital e organizada desse processo, que qualquer pequeno comércio poderia usar.

## ⚙️ Funcionalidades

- Cadastro de pedidos (cliente, item, quantidade e status)
- Alteração rápida de status com um clique (pendente → separado → entregue)
- Busca por cliente ou item
- Filtro por status
- Exclusão de pedidos
- Interface responsiva, com suporte a modo claro/escuro automático

## 🛠️ Tecnologias

- HTML5, CSS3 e JavaScript puro (sem frameworks)
- `localStorage` para persistência dos dados no navegador

## 🚀 Como rodar

Basta abrir o arquivo `index.html` em qualquer navegador — não precisa de instalação, servidor ou dependências.
